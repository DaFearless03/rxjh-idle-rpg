# UI 样式规范 · 第一批准备稿

版本：2026-09-24 / draft-1。样板验收通过；城镇/野外主页已按本规范接入，战斗页尚待迁移。

## 范围与约束

采用米色底、象牙白面板、蓝灰细边框、像素字体与现有图片。主页城镇/野外视图与公共状态栏、底部导航已完成第一批接入；列表式战斗页下一步迁移。战斗保持怪物列表与日志，不增加走位、场景动画或技能按钮。

参考图仅决定视觉方向；名称、职业、装备、奖励、费用与限制以现有 data/ 和系统返回为准。声望、公会祝福、品质筛选、装备批量出售等生成内容不作为需求。GM调试面板不在范围内。

## 样式隔离

- ui-kit/tokens.css：变量全部使用 --rpg- 前缀。
- ui-kit/components.css：所有组件限于 .rpg-ui 作用域，类名以 rpg- 开头。
- ui-kit/index.html：独立组件样板，不加载 main.js、不读取或写入游戏存档。
- 主游戏暂不引用上述文件。后续逐组件迁移、删除对应旧规则，不叠加全局 !important。
- demo.js 仅为演示，不能复制到游戏运行时。

## 字体与间距

沿用 Cubic 11，备用系统中文字体。不得通过改变 html 根字号等比放大整套UI。

| 层级 | 字号 / 行高 |
|---|---|
| 页面标题 | 18px / 1.4 |
| 面板标题 | 15px / 1.4 |
| 正文、按钮 | 13px / 1.6 |
| 辅助说明 | 12px / 1.5 |
| 紧凑数值、时间 | 11px / 1.5 |
| 触屏输入控件 | 16px / 1.5，避免聚焦自动放大 |

间距为4/8/12/16/24px；页面和面板常用12px，列表内部8px。320px屏宽面板可收至8px，正文不随屏宽缩小。

## 组件规则

### 状态栏
生命值、内功值、经验值均使用纯文字标签。条形表达比例，右侧显示当前/最大值，条内不重复百分比。沿用 PlayerStatusBarUI 的K/M/B、低血量和满级MAX逻辑；长角色名可换行或省略但完整名称可访问。无头像时不保留无意义占位。

### 底部导航
固定顺序：背包、角色、主页、任务、设置。均分宽度，12px文字，32px原图。选中蓝底白字并设置aria-current。战斗无独立导航项，不能误标其他页面。

### 面板与按钮
同屏只突出一个主要操作。主操作蓝色，不可逆操作红色，关闭/取消浅底。必须覆盖hover、focus-visible、pressed和disabled；禁用附近说明原因。

### 怪物与日志
两列怪物，最多8只；普通、精英、预热、死亡使用名称、血量和文字状态。名称可省略并提供title，血量不能被挤出。怪物图标18px。不新增点击选敌或伪造敌人。
战斗与掉落分别滚动，标题固定，长文本换行。经验、金币、伤害保留文字标签。第一批不改变自动滚动逻辑。

### 物品格
六列，20px素材，数量右下显示；选中用边框与aria-pressed。点击区域至少44px高。装备按实例操作，不能使用普通物品的批量出售数量选择。

### 表单与对话框
输入有label；数量输入验证最小值与持有上限；HP/MP阈值范围5%–95%。错误文本关联输入。
对话框限于视口，正文滚动、操作区可达；焦点进入并在关闭后回到触发按钮。Esc只关闭允许退出的对话框。角色入口与离线门禁由CharacterEntryGate控制，不能套用普通关闭规则。错误和禁用不只靠颜色，轻提示用role=status。

## 适配与验收

尺寸：320×568、393×852、430×932、844×390、1440×900。覆盖200%文字放大、10字角色名、长怪物名、大数值、8怪、长日志、空态、禁用和对话框焦点。
不允许水平页面溢出、主按钮不可达、日志归零。桌面使用简洁居中区域，不设模拟灵动岛。主游戏滚动与安全区仍须在正式迁移阶段另验；组件样板通过不等于正式页面通过。
