2026-09-24。主页城镇/野外视图已接入统一样式；战斗页和其他面板仍使用原有展示。本文区分现有行为、页面职责和独立样板。

## 本阶段不接入

背包装备、角色信息/气功/武功、任务、商店、仓库、强化合成、系统挂机设置、角色列表/创建、删除、离线流程仍保留现状。样板里的这些通用控件用于验证外观，不代表正式业务已经替换。

## 必须保留

1. 没有成功选择/创建角色不能进游戏；普通弹窗Esc规则不能绕过入口门禁。
2. 同地图精英上限由战斗系统控制，不靠UI隐藏异常。
3. 强化合成不显示每次成功率；生命/内功阈值百分比不属此限制。
4. 装备按实例操作，不出现出售10件装备的堆叠交互。
5. 图中的声望、公会、品质筛选、队友治疗不构成新系统需求。
6. 导入失败不能清档；删除与离线领取保持原事务和门禁。
7. 角色/物品/日志内容保持转义，不把原来的安全文本改成未处理HTML。

## 后续升级门槛

主页已按规范完成第一批接入；战斗页升级前仍需逐项对照本表与样板。
正式升级另验：创建角色→入城→地图→开/停挂机→主页/战斗切换→NPC→返回角色列表。准备阶段和主页样式检查都不替代此流程。
